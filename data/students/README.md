# Student Data Directory
Place your real student records files (Excel `.xlsx` or CSV `.csv`) here.

### Expected Columns:
- `Register Number` (e.g., `23CS001`)
- `Student Name`
- `Branch` (e.g., `CSE`, `ECE`, `IT`, `AIML`)
- `Section` (e.g., `CSE-A`, `CSE-B`)
- `Academic Year` (e.g., `2025-2026`)
- `Semester` (e.g., `1`, `2`, `3`, `4`, `5`, `6`, `7`, `8`)
- `Username` / `Password` (optional if generated or defaults used)
