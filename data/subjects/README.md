# Subject Data Directory
Place your real subject / syllabus curriculum records files (Excel `.xlsx` or CSV `.csv`) here.

### Expected Columns:
- `Subject Code` (e.g., `CS301`, `CS302`)
- `Subject Name` (e.g., `Computer Networks`, `Database Management Systems`)
- `Branch` (e.g., `CSE`, `ECE`, `IT`, `AIML`)
- `Semester` (e.g., `1`, `2`, `3`, `4`, `5`, `6`, `7`, `8`)
